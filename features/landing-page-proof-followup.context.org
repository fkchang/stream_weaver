- Honest errors keep the failing source visible and never substitute unrelated output.
- Static/exported output must not show live-looking controls that cannot work; document runtime limits rather than implying parity.
- Do not imply the current multi-file landing suite is literally one file. The hero names the category and demonstrates one-file examples.
- Disclose shared helpers, CSS, setup, and runtime dependencies in benchmark accounting. Source tokens are not model tokens or elapsed time.
